# V1.5B-4 — harmonogram i blokady

Data: 2026-11-06. Gałąź: `feature/schedule-cms`, baza: `main`.

## Zakres

Właściciel w `/panel/harmonogram` zapisuje i publikuje dni tygodnia oraz blokady całego dnia albo jednego startu. Puste dni tygodnia znaczą, że rytm tygodnia nie został jeszcze ustalony. Limity 8 / 2–4 / 32 oraz starty 08:00, 11:00 i 14:00 są pokazane z opublikowanej konfiguracji firmy. Liczba zestawów zostaje nieustalona i formularz ją odrzuca.

Wersja robocza nie jest publiczna. Ten etap nie liczy wolnych miejsc, nie rysuje kalendarza rezerwacji i nie sprzedaje terminów.
